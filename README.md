# Adding Two Binary Strings

## Description
This program takes two binary strings as input, removes any leading zeros, and returns their sum as a binary string. It correctly handles carry operations to ensure accurate binary addition.

## Features
- Removes leading zeros from input binary strings.
- Performs binary addition with proper carry handling.
- Works with binary numbers of different lengths.

## How to Run

### Prerequisites
- Python 3.x installed on your system.

### Steps to Execute
1. Clone the repository:
   ```bash
   git clone https://github.com/kaanylmz123/BIL458HW1_22197370.git
   cd BIL458HW1
   ```
2. Run the Python script:
   ```bash
   python addtwobinstring.py
   ```
### Example
Input:
```python
s1 = "1101"
s2 = "111"
```
Output:
```python
"10100"
```
